# sistema_gestionale_autobus
Sistema gestionale per una compagnia di trasporti interregionali, che supporta l’emissione e la prenotazione di biglietti autobus, la gestione delle corse ed il controllo delle disponibilità di posti e bagagli, con funzionalità dedicate sia agli operatori che agli utenti finali.
